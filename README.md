# Yukthahara — Dazzling Nutritionist React UI

A premium, responsive nutritionist landing page built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Included
- Premium responsive landing page
- Mobile navigation
- Nutrition philosophy / method section
- Client transformation story
- Interactive BMI estimate
- Program cards
- FAQ accordion
- Lead-capture modal
- Toast feedback
- No external image assets required
- Lucide icons
- CSS-only visual food composition / abstract imagery

## Main files
- `src/main.jsx` — React UI and interactions
- `src/styles.css` — complete visual system
- `index.html` — app shell
